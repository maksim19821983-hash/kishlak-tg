## Git: где что лежит

Коммиты хранятся **локально**, в скрытой папке `.git/` внутри проекта (сейчас ~29 МБ). Это вся история, работает без интернета. На GitHub попадает только то, что ты отправил командой `git push`.

| Что хочу | Команда |
|---|---|
| История коммитов | `git log --oneline` |
| Что внутри коммита | `git show 97a0f70 --stat` |
| Что изменено, но не закоммичено | `git status` |
| Что именно изменилось | `git diff` |
| Отправить на GitHub | `git push` |
| Забрать с GitHub | `git pull` |

Смотреть глазами удобнее в графической программе: **GitHub Desktop**, **Fork** или панель Source Control в **VS Code**. На GitHub — вкладка Commits после пуша: `github.com/<логин>/<репо>/commits/main`.

Правило: перед `git add -A` всегда смотри `git status` — в проект нельзя тащить `tools/.venv/`, `content/`, `public/content/`, `vdps/`.
