# 07 — Фан-слой: проявление, статистика, профиль

**Читать:** `docs/spec/fan-layer.md` целиком.
**Результат:** приложение помнит, что ты слушал, проявляет обложки и собирает профиль.

## Задача 1 — хранилище

`src/features/fan/state.ts`:
- ключ `kishlak:fan:v1`, единый объект `FanState` (типы — в ТЗ, п. 5);
- загрузка при старте с миграцией по `version`; битый JSON → чистый старт, без падения;
- запись не чаще раза в 10 секунд и всегда при `pause` / `ended` / `visibilitychange`;
- `sessions` — 500 последних, FIFO.

## Задача 2 — учёт прослушивания

`src/features/fan/trackListen.ts`:
- подписка на `AudioPort`, накопление `maxPosition` и `totalSeconds`;
- трек считается прослушанным при `maxPosition / duration >= 0.8` или `ended`;
- повторное прослушивание увеличивает `plays`, но не `listens`;
- перемотка вперёд не добавляет в прослушанные;
- `ReleaseProgress` считается как `listenedTracks / totalTracks` (0..1) и кэшируется в сторе.

Тесты: 79% → не считается, 80% → считается, перемотка на 90% и выход → не считается, повтор → `plays+1`, `listens` без изменений.

## Задача 3 — титул

`src/features/fan/title.ts`:
- чистая функция `pickTitle(stats): { id, since }` по таблице приоритетов из ТЗ;
- пересчёт раз в сутки (по `lastComputedAt`), смена — не чаще раза в 7 дней, кроме первого получения;
- `since` — дата, с которой титул действует.

Тесты: «топ-релиз 41% + 70% каталога» → `РЕЗИДЕНТ`; «ночь 60%» → `НОЧНАЯ СМЕНА`; «всё прослушано» → `ПЕРВЫЙ РЯД`; пустые данные → `null`, плашка не показывается.

## Задача 4 — проявление обложек

Готовый `Sleeve` из задачи 04 уже умеет `progress`. Здесь — только источник:
- `FanRepo.getProgress(releaseId): number`;
- обновление после `ended`, не после паузы;
- при `progress` 0→1 — одноразовый тост «релиз собран» (одна строка, без конфетти).

## Задача 5 — профиль

`src/features/fan/ProfileScreen.tsx`:
- шапка `ПРОФИЛЬ` + `С НОЯБРЯ`;
- титул (h1 46), подпись `ВДПС — 41% ТВОЕГО ВРЕМЕНИ` (mono-label);
- характеристика: шаблон из данных, 2–3 строки; мало данных — блок не показывается;
- три цифры в рамке: треков, минут, повторов (digits, tabular);
- топ-релиз: обложка 64, название, `ТОП-РЕЛИЗ · 41% · 10`, линия прогресса;
- `ПОСЛЕДНЕЕ` — 3 записи (название, дата);
- кнопка «ПОДЕЛИТЬСЯ КАРТОЧКОЙ» — **заглушка** (карточка после запуска, рисуется в `design/preview/card.png`).

Открывается кнопкой «Р» из шапки каталога, закрывается BackButton.

- [ ] Тесты `title.ts` и `trackListen.ts` зелёные
