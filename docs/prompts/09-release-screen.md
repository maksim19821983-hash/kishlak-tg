# Экран релиза: обложка на фоне, треки списком

Задача на потом. Сейчас кадр релиза — большая обложка и кнопка «СЛУШАТЬ». Нужно больше информации, но дизайн остаётся: обложка на весь экран фоном, поверх — текст.

## Что должно быть

```
┌──────────────────────────────┐
│ ← НАЗАД                      │  обложка продолжает быть фоном,
│                              │  скрим снизу
│                              │
│         (обложка)            │
│                              │
│ РЕЛИЗ · 2025                 │
│ ВДПС                         │  40px Unbounded
│ 9 ТРЕКОВ · 26:21 · 4/9       │  моно, приглушённо
│                              │
│ [ ▶ СЛУШАТЬ 4/9 ]            │  если 0 прослушано — «СЛУШАТЬ»
│                              │  если все — «СЛУШАТЬ ЗАНОВО»
│                              │
│ 01  Интро          2:19  ✓   │  прослушанные — акцентом + галочка
│ 02  Гордыня       3:31  ✓   │  непрослушанные — приглушённые
│ 03  Жадность      3:05      │
│ 04  Лень          3:09      │
└──────────────────────────────┘
```

### Детали

- **Обложка** остаётся фоном, скрим снизу вверх (как сейчас), не превращаем в шапку-карточку.
- **Треклист рисуется поверх скрима** — с прокруткой, если релиз большой (14 треков у «Эскапита» влезают при 44 px на строку).
- **Строка трека**: номер (моно), название, длительность, справа — статус: `✓` акцентом, если прослушан; ничего, если нет.
- **Играющий трек** помечен той же акцентной точкой, что и в плеере.
- **Тап по строке** — играет этот трек, очередь — весь каталог, стартовая позиция — этот трек.
- **Кнопка «СЛУШАТЬ»** — если есть непрослушанные, запускает с первого непрослушанного; если все прослушаны — с первого трека.
- **Инфо** под названием: тип (`РЕЛИЗ` / `СИНГЛ` / `EP`), год, число треков, суммарная длительность, `прослушано N из M`.

### Чего не делать

- Не менять существующие обложки, полярность и скрим.
- Не добавлять табы внутри кадра.
- Не делать отдельную «страницу альбома» в навигации: кадр остаётся оверлеем над каталогом.

## Зависимости

Требует новой модели прослушиваний (`docs/spec/listen-accounting.md`): статус `✓` и счётчики берутся из неё, иначе снова разъедется.
