# 03 — Полярность и акцент

**Читать:** `docs/design/system.md`, п. 1–2, и `src/data/types.ts`.
**Результат:** приложение само понимает, бумага это или чернота, и подхватывает цвет обложки. Без этого нет ни каталога, ни кассеты.

**Важно:** палитра уже посчитана и лежит в манифесте — `release.palette = { mode, accent }` («ВДПС» → `paper`, `#64A4B4`). Считать её в браузере каждый раз не нужно. Анализ на canvas остаётся только как фолбэк для обложек без палитры.

## Задача

1. `src/features/polarity/accent.ts` — чистые функции, без React и DOM:
   - `parseHex(hex)`, `toHex({r,g,b})`;
   - `hexToHsl`, `hslToHex`;
   - `relativeLuminance(rgb)` по Rec.709 (`0.2126R + 0.7152G + 0.0722B`, 0..1);
   - `contrastRatio(rgbA, rgbB)`;
   - `accentText(accentHex, mode): string` — шаг по светлоте 0.01 (на бумаге темнее, на черноте светлее), пока контраст с фоном не станет ≥ 4.5:1; если не удалось — `#131211` для `paper` / `#F1EDE6` для `dark`;
   - тесты: `#64A4B4` на бумаге даёт контраст ≥ 4.5 (ожидаемо ≈ `#3A6C78`); на черноте — светлее и тоже ≥ 4.5; чёрный и белый не ломают функцию.

2. `src/features/polarity/analyzeCover.ts` — **фолбэк**, используется только если у релиза нет `palette`:
   - `analyzeCover(url): Promise<{mode, accent}>`, canvas **16×16**, `crossOrigin='anonymous'`;
   - средняя яркость → режим (`≥ 0.55` → `paper`);
   - акцент: валидные пиксели (`L ≥ 0.10`, `L ≤ 0.92`, `S ≥ 0.18`), усреднение hue через вектор, зажим `S ∈ [0.35, 0.60]`, `L ∈ [0.38, 0.55]`;
   - ошибка/CORS/пустой canvas → `{mode:'paper', accent:'#8C5334'}`, без исключений;
   - кэш `Map<url, palette>`.

3. `src/features/polarity/usePolarity.ts` — хук:
   - источник: `release.palette` текущего трека (или текущего релиза, если трек не играет); нет трека — `paper` + `#8C5334`;
   - пишет на `<html>`: `data-polarity`, `--accent`, `--accent-text` (через `accentText`);
   - пересчитывает только при смене `track.id` / `release.id`, не на паузе, перемотке и лайке;
   - не блокирует первый рендер.

4. Переход: `transition: background-color 420ms ease, color 420ms ease` на `body`; при `prefers-reduced-motion` — `0ms`.

5. Отладочный роут `/polarity` (только для dev):
   - сетка из 6 обложек: скопируй `design/assets/real/{vdps,shiz2,boleyu,apnoe,stigmata,lava}.jpg` в `public/dev/covers/` (один раз, это ~1.5 МБ);
   - клик по обложке применяет её полярность и акцент ко всему экрану;
   - рядом показать цифры: режим, `accent`, `accentText`, контраст.

## Ограничения

- Никакой библиотеки для цвета — 60 строк своих.
- Никаких вычислений на скролле и на лишних рендерах.
- Не менять `--ink`, `--line`, типографику — только полярность и акцент.
- `analyzeCover` не должен вызываться для релизов, у которых есть `palette` (проверить `console.count`).

## Готово, когда

- [ ] «ВДПС» из манифеста даёт `paper` и `#64A4B4`, `accent-text` — контрастный вариант
- [ ] На `/polarity` все 6 обложек дают разумную полярность: светлые → бумага, тёмные → чернота
- [ ] Переключение не мигает белым/чёрным, переход 420 мс
- [ ] `console.count` в `analyzeCover` равен нулю при обычной навигации по манифесту
- [ ] Обложка с закрытым CORS → бумага + медь, без красных ошибок в консоли
- [ ] `reduced-motion` — переключение мгновенное
- [ ] Тесты `accent.ts` зелёные, включая контраст ≥ 4.5 для всех режимов
- [ ] `npm run build` и `npx tsc --noEmit` чисто
