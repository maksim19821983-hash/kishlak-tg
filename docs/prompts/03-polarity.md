# 03 — Полярность и акцент

**Читать:** `docs/design/system.md`, п. 1–2.
**Результат:** приложение само понимает, бумага это или чернота, и подхватывает один цвет из обложки. Без этого нет ни каталога, ни кассеты.

## Задача

1. `src/features/polarity/luminance.ts` — чистые функции, без React:
   - `relativeLuminance({r,g,b})` по Rec.709 (`0.2126R + 0.7152G + 0.0722B`, значения 0..1);
   - `pickPolarity(luminance, threshold = 0.55): 'paper' | 'dark'`;
   - `saturationOf({r,g,b})`, `isUsableAccentPixel()` — отбросить почти чёрное (`L < 0.10`), почти белое (`L > 0.92`), серое (`S < 0.18`).
   Покрыть тестами: белая обложка → `paper`, чёрная → `dark`, серая → `paper` (порог), все три отказа акцента.

2. `src/features/polarity/analyzeCover.ts`:
   - `analyzeCover(coverUrl): Promise<{ mode: 'paper'|'dark', accent: string }>`;
   - `Image` с `crossOrigin='anonymous'`, canvas **16×16**, `getImageData`;
   - средняя яркость всех пикселей → режим;
   - акцент: усреднение валидных пикселей в HSL, зажим `S ∈ [0.35, 0.60]`, `L ∈ [0.38, 0.55]`; нет валидных — `#8C5334`;
   - `accentText`: тот же цвет, но светлота подогнана шагом 0.01 до контраста ≥ 4.5:1 с фоном текущей полярности (на бумаге темнее, на черноте светлее);
   - кэш `Map<string, {mode, accent, accentText}>` по `trackId`/`releaseId`;
   - любая ошибка (CORS, 404, пустой canvas) → `{ mode: 'paper', accent: '#8C5334', accentText: '#6B3D20' }`, без исключений.

3. `src/features/polarity/usePolarity.ts` — хук:
   - берёт обложку играющего трека; если ничего не играет — обложку артиста (или `paper`);
   - пишет `data-polarity` на `<html>`, `--accent` и `--accent-text` (контраст ≥ 4.5:1 к фону текущей полярности);
   - не пересчитывает при паузе, перемотке, лайке — только при смене `track.id` / `release.id`.

4. Переход: `transition: background-color 420ms, color 420ms` на `body`; при `prefers-reduced-motion` — 0 мс.

5. Отладочный роут `/polarity`: сетка из 8 реальных обложек из `design/assets/real/`, кнопка «по кругу» — видно, как меняется вся страница.

## Ограничения

- Никакой библиотеки для цвета.
- Никаких вычислений на скролле и на рендерах без смены трека.
- Не менять `--ink`, `--line`, типографику — только полярность и акцент.
- Не блокировать первый рендер: пока считаем, показываем `paper` и `#8C5334`.

## Готово, когда
