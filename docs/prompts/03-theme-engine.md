# 03 — Движок сцены (динамическая тема)

**Читай перед началом:** `CLAUDE.md` (раздел 6), `docs/design/system.md` (раздел 5).
**Результат:** при смене трека меняются фон и акцент. Без этого продукт — обычный плеер.

## Задача

1. `src/theme/color.ts` — чистые функции без DOM:
   - `rgbToHsl`, `hslToCss`, `clampAccent({h,s,l})`: `s` зажать в `[0.30, 0.55]`, `l` в `[0.42, 0.56]`;
   - `isValidPixel({h,s,l})`: отбросить `l < 0.12`, `l > 0.9`, `s < 0.18`;
   - `averageHue(pixels)` — усреднение по hue **через вектор** (`sin/cos`), иначе синий и красный дадут зелёный.
   Покрыть тестами: серые пиксели → фолбэк, почти-чёрные отбрасываются, hue-усреднение устойчиво.

2. `src/theme/palette.ts`:
   - `extractPalette(coverUrl): Promise<Palette>` — `Image` с `crossOrigin='anonymous'`, canvas **20×20**, `getImageData`, фильтрация, усреднение, зажим;
   - результат — `{ accent: string, accentHi: string, accentLo: string, hue: number }`;
   - `Map<trackId, Palette>` кэш; повторный вызов для того же трека — мгновенный;
   - любая ошибка (CORS, 404, пустой canvas) → `DEFAULT_PALETTE` (`#9A5B3A`), без исключений наружу;
   - `getPaletteForTrack(track)` — сначала кэш, потом мок из `data/palettes.ts`, потом экстракция.

3. `src/theme/applyTheme.ts` — пишет в `document.documentElement.style`:
   `--accent`, `--accent-hi`, `--accent-lo`, `--accent-wash` (через `color-mix`), `--scene-hue`.
   Не пишет, если значение не изменилось (сравнение строкой).

4. `src/ui/SceneBackdrop.tsx`:
   - фиксированный слой на весь экран: `img` обложки, `object-fit: cover`, `filter: blur(48px)`, `transform: scale(1.3)`;
   - поверх — `linear-gradient(to bottom, rgba(11,11,12,.55), #0B0B0C 78%)`;
   - смена обложки — кроссфейд 420 ms (два слоя, старый/новый, `opacity`);
   - `prefers-reduced-motion` — без кроссфейда и без blur-перехода, мгновенная замена.

5. Подключить к аудио: `PlayerStore` при смене `track.id` вызывает `getPaletteForTrack` → `applyTheme`, и передаёт обложку в `SceneBackdrop`. Смена темы — только по `track.id`, не по `timeupdate`.

6. Временная проверка: экран «отладка темы» с 10 моками палитр и кнопкой «случайный цвет», чтобы глазами убедиться, что контраст держится.

## Ограничения

- Никакого `useEffect` с расчётом на каждый рендер. Только по `track.id`, через кэш.
- Никаких внешних библиотек для цвета (color-thief, vibrance) — 60 строк своих, зато предсказуемо.
- Не менять `--bg-void`, `--ink` и шрифты. Меняется только акцент.
- Не блокировать первый рендер: если палитра ещё считается — показываем дефолтный акцент, потом плавно меняем.

## Готово, когда

- [ ] Переключение 10 треков: фон и акцент меняются, вспышек белого/чёрного нет
- [ ] Пауза/плей, перемотка, лайк — тему не пересчитывают (проверить `console.count` в `extractPalette`, он не растёт)
- [ ] Трек без обложки → дефолтный акцент, интерфейс не ломается
- [ ] Трек с CORS-закрытой обложкой → дефолтный акцент, в консоли нет красных ошибок
- [ ] `prefers-reduced-motion` — смена мгновенная, без анимации
- [ ] Тесты `color.ts` зелёные
- [ ] Контраст акцента на `--bg-void` ≥ 4.5:1 для всех 10 моков (проверить скриптом в тестах)
