# 07 — Телеграм: шаринг, deep links, Stars, «О проекте»

**Читай перед началом:** `CLAUDE.md` (раздел 7), `docs/design/backlog.md` (пункты 1–7).
**Результат:** продукт живёт внутри Телеграма, а не просто открывается в нём. Это канал роста и денег.

## Задача 1 — шаринг трека

- Кнопка «Поделиться» в меню плеера и в строке трека (долгий тап).
- Формируем ссылку:
  `https://t.me/<bot_username>?startapp=track_<trackId>`
  и текст: `Болею тобой — Кишлак` (название — артист, без рекламных приписок).
- Вызов: `Telegram.WebApp.switchInlineQuery` не нужен; используем `https://t.me/share/url?url=<encoded>&text=<encoded>` через `openTelegramLink`.
- После шаринга — haptic `success` и тост «Ссылка скопирована», если шаринг недоступен (в браузере — `navigator.clipboard`).

## Задача 2 — deep links

- Читаем `Telegram.WebApp.initDataUnsafe.start_param` при старте.
- Форматы: `track_<id>` — открыть трек и полный плеер; `release_<id>` — открыть релиз.
- Неизвестный/битый параметр — тихо открываем главную, без ошибки.
- Если приложение уже открыто — обрабатываем повторный `startapp` через `Telegram.WebApp.onEvent('activated')`, без перезагрузки.

## Задача 3 — Telegram-обвязка

`src/app/telegram.ts`:
- `haptic(kind: 'light'|'medium'|'heavy'|'success'|'warning'|'error')` — один хелпер на всё приложение;
- `showBackButton(handler)` / `hideBackButton()` — с корректной отпиской;
- `setHeaderColor('#0B0B0C')`, `setBackgroundColor('#0B0B0C')` при инициализации и при смене сцены (цвет не меняем, но переустанавливаем после возврата из фона);
- `disableVerticalSwipes()` — чтобы свайп вниз не закрывал мини-апп во время перетаскивания волны.

## Задача 4 — Stars (каркас)

- Экран «Поддержать» (шит из меню плеера и с главной): выбор 50 / 100 / 250 ⭐, текст «Поддержать Кишлака», кнопка.
- Пока бэкенда нет: кнопка открывает бота (`openTelegramLink('https://t.me/<bot>?start=support')`) и пишет событие в консоль.
- Интерфейс должен быть готов к `openInvoice`, но **не вызывать** его без реального бэкенда.
- Никаких «поддержите проект» — только «поддержать артиста»: донат привязан к человеку, а не к сервису.

## Задача 5 — «О проекте»

- Один экран: артист, что это за приложение (2 абзаца), права на музыку, контакты, версия сборки.
- Ссылка на канал артиста и на бота поддержки.
- Текст без канцелярита, от первого лица продукта.

## Задача 6 — полировка

- Убрать `/spike` из продакшн-сборки (роут оставить в dev-режиме по флагу).
- Проверить `ready()`/`expand()` на холодном старте: нет прыжка контента (CLS).
- Кнопка «закрыть» мини-аппа во время игры — музыка должна продолжаться (это ожидаемое поведение, проверяем, что не падаем).
- При возврате из фона — синхронизировать `currentTime` с реальной позицией аудио.

## Ограничения

- Никаких сторонних SDK для Телеграма.
- Не хранить `initData` в `localStorage`.
- Не показывать ошибки Telegram API пользователю.

## Готово, когда

- [ ] Ссылка на трек открывает именно этот трек в Телеграме у другого человека
- [ ] Шаринг работает на iOS и Android, текст и ссылка корректные
- [ ] `BackButton` появляется и исчезает ровно там, где нужно
- [ ] Haptics не срабатывают на скролле
- [ ] Экран «Поддержать» открывается, доната-заглушки не видно
- [ ] «О проекте» без орфографических ошибок (проверить вручную)
- [ ] Продакшн-сборка не содержит `/spike`
