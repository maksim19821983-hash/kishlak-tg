# 08 — Телеграм: шаринг, deep links, Stars

**Читать:** `CLAUDE.md`, раздел 7, и границы в разделе 3.
**Результат:** продукт живёт внутри Телеграма, а не просто открывается в нём.

## Задача 1 — адаптер

`src/app/telegram.ts` — единственное место с `window.Telegram`:
- `haptic(kind)` — `light | medium | heavy | success | warning | error`;
- `showBackButton(handler)` / `hideBackButton()` с корректной отпиской;
- `setHeaderColor('#0B0B0C')`, `setBackgroundColor` — при инициализации и после возврата из фона;
- `disableVerticalSwipes()` — чтобы свайп не закрывал мини-апп во время перетаскивания;
- `getStartParam()`, `getUser()` (id, username), `openLink()`;
- всё в `try/catch`, вне Телеграма — no-op.

## Задача 2 — deep links

- `start_param` форматов `track_<id>`, `release_<id>`: открыть соответствующий экран.
- Неизвестный/битый параметр — тихо открыть каталог.
- Повторный `startapp` при открытом приложении — через `onEvent('activated')`, без перезагрузки.

## Задача 3 — шаринг трека

- Меню плеера → «Поделиться»: ссылка `https://t.me/<bot_username>?startapp=track_<id>`, текст `Болею тобой — Кишлак`.
- `openTelegramLink('https://t.me/share/url?url=…&text=…')`; вне Телеграма — `navigator.clipboard` + тост.
- После шаринга — haptic `success`.

## Задача 4 — Stars (каркас)

- Шит «Поддержать» из меню: 50 / 100 / 250 ⭐, текст «Поддержать Кишлака» (не «проект»).
- Без бэкенда: `openTelegramLink('https://t.me/<bot>?start=support')` и событие в консоль.
- Интерфейс готов к `openInvoice`, но не вызывает его.

## Задача 5 — полировка

- `/spike` не попадает в прод-сборку (флаг dev).
- Холодный старт без прыжка контента (CLS): `ready()` + `expand()` до первого рендера.
- Возврат из фона синхронизирует `currentTime` с реальной позицией.
- При закрытии мини-аппа музыка продолжает играть — проверяем, что не падаем.

## Ограничения

- Никаких сторонних SDK для Телеграма.
- `initData` не хранить в `localStorage`.
- Ошибки Telegram API пользователю не показывать.

## Готово, когда

- [ ] Ссылка на трек открывает именно этот трек у другого человека
- [ ] Шаринг работает на iOS и Android, текст и ссылка корректные
- [ ] BackButton появляется и исчезает там, где нужно
- [ ] Haptics не срабатывают на скролле
- [ ] «Поддержать» открывается, заглушка не выглядит сломанной
- [ ] В прод-сборке нет `/spike`

## Отчёт

Что требует бэкенда и реального бота (`@BotFather`: username, меню-кнопка).
