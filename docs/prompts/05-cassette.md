# 05 — Кассета и лента

**Читать:** `docs/design/screens.md`, п. 3 и 6, `docs/design/system.md`, п. 7.
**Результат:** плеер-предмет и мини-плеер. Это лицо продукта — тут нельзя «примерно».

## Задача 1 — корпус кассеты

`src/features/player/Cassette.tsx` (чистый CSS, без картинок):
- корпус: `aspect-ratio: 1.44`, радиус 10, padding 14/16, мягкая тень `0 18px 30px -18px rgba(0,0,0,.55)` (единственное место, где тень разрешена);
- 4 винта 5 px по углам; лейбл сверху: `КИШЛАК — ВДПС` слева, `№ 0341` справа (mono 8.5, трекинг .18em);
- окно: высота 92 px, радиус 6, фон `rgba(0,0,0,.45)`, hairline;
- две катушки 72 px: диск ленты (медь `#8C5334`), ступица цветом фона, лента-линия 2 px между ними;
- снизу: `СТОРОНА A` слева, `C-60 · 2026` справа.

Прогресс: левая катушка «полнеет», правая «пустеет» — диаметр диска ленты интерполируется по `currentTime / duration`.

## Задача 2 — вращение и поведение

- Вращение: `transform: rotate()` через `requestAnimationFrame`, скорость `360° / 2 с` в режиме play, 0 при паузе. Останавливать при `document.hidden`.
- `prefers-reduced-motion` — катушки статичны.
- Тап по корпусу — `toggle()`, haptic `medium`.
- «ПЕРЕВЕРНУТЬ» — 3D-флип (`rotateY` 600 мс), сторона B, очередь перестраивается; в DOM обе стороны, чтобы флип не подгружал контент.
- Конец стороны — лента стоп, подсказка «перевернуть», haptic `warning`.

## Задача 3 — экран плеера

`src/features/player/PlayerScreen.tsx`:
- шапка `01 / 12` слева, `КИШЛАК` справа;
- кассета;
- название (display-l 36), `КИШЛАК · 2026 · СИНГЛ` (mono-label);
- 3 строки текста: `lyric` / `lyric-active` (акцент), тап по строке — `seek()`;
- `ДАЛЬШЕ НА КАССЕТЕ`: 2 строки очереди (mono-номер, название, длительность);
- линия прогресса 3 px + `0:42` / `−1:38` (mono-num, tabular);
- транспорт: prev (44), play/pause (58, круг цвета текста), next (44), пилюля «ПЕРЕВЕРНУТЬ».

## Задача 4 — лента мини-плеера

`src/ui/TapeStrip.tsx`, 46 px:
- обложка 28 px, название (body-strong 12), `КИШЛАК · 0:42 / 2:12` (mono 8.5), пауза справа;
- снизу линия прогресса 2 px акцентом;
- фон = фон экрана, сверху hairline; не панель, без скруглений;
- видна на всех экранах, кроме каталога (там режим C в шапке) и кадра релиза;
- тап по ленте → плеер; кнопка — `toggle()`.

## Ограничения

- Никаких анимационных библиотек; катушки — только CSS + rAF.
- Никаких `position: fixed` для ленты: она в потоке внизу экрана.
- Нельзя перерисовывать весь экран на каждый `timeupdate` — подписки точечные (селекторы стора).
- Никаких хардкод-цветов, только токены.

## Готово, когда

- [ ] Кассета читается как предмет: винты, лейбл, катушки, окно
- [ ] Катушки крутятся со скоростью трека и замирают на паузе, 60 fps
- [ ] Переворот работает, очередь перестраивается, флип без подгрузки
- [ ] Лента видна на всех нужных экранах и не дёргается при скролле
- [ ] Состояния play/buffering/error/конец стороны различимы
- [ ] `reduced-motion` уважается
- [ ] Android: жесты и safe-area не конфликтуют
