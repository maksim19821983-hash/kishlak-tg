# 06 — Вкладыш и текст

**Читать:** `CLAUDE.md`, раздел 5, `docs/design/screens.md`, п. 4.
**Результат:** парсер LRC и вкладыш — текст как бумажная вкладка, а не отдельный экран-караоке.

## Задача 1 — парсер

`src/features/lyrics/parseLrc.ts`, чистый модуль, без DOM:
- метаданные `[ti:]`, `[ar:]`, `[al:]`, `[by:]`;
- `[offset:±ms]` — сдвиг применяется ко всем строкам;
- `[mm:ss.xx]` и `[mm:ss:xx]`;
- несколько таймкодов на строку `[00:12.00][00:45.10]текст` → две записи;
- word-level `[00:12.00]<00:12.30>Слово <00:12.90>слово`;
- **метки секций** `[00:12.00][Куплет]`, `[01:02.53][Припев]` — это не текст песни, а метка: `isSection: true`, рендерим как mono-label приглушённым, без подсветки;
- строки-паузы и `♪` не выбрасывать;
- CRLF, BOM, пустые строки, мусор в начале.

```ts
interface LyricLine { time: number; text: string; isSection?: boolean; words?: { time: number; text: string }[]; isBlank: boolean }
interface Lyrics { meta: Record<string, string>; lines: LyricLine[] }
```

Сортировка по времени, дубликаты схлопываются через `·`. Тесты с фикстурами: обычный, с offset, с word-level, с несколькими таймкодами, с метками секций, пустой, битый, с BOM.

`getActiveLineIndex(lines, t)` — бинарный поиск последней строки с `time <= t + 0.12`, тесты на границы (до первой, между, после последней, пусто).

## Задача 2 — вкладыш

`src/features/lyrics/InsertScreen.tsx`:
- открывается из плеера (свайп вверх по кассете или тап по превью текста), закрывается «СЛОЖИТЬ» / свайпом вниз;
- анимация складывания: `rotateX` 0 → -80° + `opacity`, 300 мс; при `reduced-motion` — мгновенно;
- заголовок `ТЕКСТ ПЕСНИ` (h2), hairline;
- строки: `lyric` 13.5/34, активная — `lyric-active` (Unbounded 600, 16, `--accent-text`, не `--accent`: сырой цвет обложки не проходит контраст на бумаге);
- тап по строке — `seek(line.time)`, haptic `light`;
- hairline, трек-лист стороны A: номер (mono 9.5), название, длительность;
- выходные данные: `КИШЛАК · ВДПС · 2026 / ЗАПИСАНО В ПОДВАЛЕ · 11 ТРЕКОВ / ТИРАЖ 0341 / 1000`.

Если LRC нет — превью текста в плеере не показывается, вкладыш недоступен.

## Задача 3 — живая подсветка на кассете

В плеере 3 строки вокруг активной (активная + по одной сверху и снизу). Обновление — по троттлингу стора (4 раза в секунду), не на каждый кадр.

## Ограничения

- Никаких внешних парсеров LRC.
- Никакого `scrollIntoView` — вкладыш не скроллит автоматически, это бумага: пользователь листает сам.
- Парсер не знает про React и не импортирует ничего из `src/app`.

## Готово, когда

- [ ] Тесты парсера зелёные, включая битые файлы и BOM
- [ ] Активная строка совпадает со звуком на 3 разных треках
- [ ] Тап по строке перематывает точно
- [ ] Нет LRC → вкладыш недоступен, плеер без превью
- [ ] Складывание/раскрытие — 60 fps, `reduced-motion` уважается
- [ ] Длинные строки не обрезаются, переносятся

## Отчёт

Какие форматы LRC встретились в реальных файлах, что не поддержано и почему.
