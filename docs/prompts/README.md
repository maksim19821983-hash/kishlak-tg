# Промты: как пользоваться

> **ВНИМАНИЕ: промты 01–07 устарели.** Они написаны под первый дизайн (волна-осциллограмма, пилюля «Текст песни», три таба, палитра с зажимом оттенка). Актуальная основа — бумага/чернота, кассета, вкладыш, лента (`docs/design/system.md`, `screens.md`). Перед запуском Claude промты нужно переписать.

Каждый файл — самостоятельная задача для Claude Code. Отправляй **по одному**, по порядку, и не переходи к следующей, пока предыдущая не прошла приёмку.

## Как формулировать свой промт

```
Задача: <что сделать, одной фразой>
Контекст: <какие файлы/экраны это затрагивает>
Сделать: 1) ... 2) ... 3) ...
Не делать: <что не трогать>
Готово, когда: <проверяемый чеклист>
```

## Правила

- Одна задача — один коммит. После приёмки фиксируем: `git commit -m "<фаза>: <что сделано>"`.
- Claude обязан начинать с чтения `CLAUDE.md` и файлов в `docs/`. Если он этого не делает — вставь в начало промта: «Сначала прочитай CLAUDE.md и docs/design/system.md».
- Если ответ начинается со «я решил сделать иначе» — не принимай, попроси следовать спеке. Спека обсуждается с тобой, а не с ним.
- В конце каждой задачи проси отчёт: что сделано, что проверено, где риски. Без этого задачи не закрываются.
