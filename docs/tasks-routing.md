# Задачи: кому — Sonnet, кому — Opus

Правило простое: **реализация по спеке → Sonnet, решения и тяжёлые баги → Opus.** Плюс всегда: свежая сессия, мелкая задача, коммит, `/clear`.

Почему так: в агентском режиме каждый шаг пересылает весь контекст. Дешёвая модель в чистой сессии стоит копейки, дорогая модель в раздутом контексте стоит как месяц работы — независимо от ума.

---

## Opus: редкие, но важные задачи

### O1. Аудио на R2

```
Задача: спроектировать и реализовать перенос аудио и обложек на Cloudflare R2.

Контекст: приложение на Cloudflare Pages не поддерживает Range-запросы (проверено: ответ 200 вместо 206),
поэтому перемотка медленная, а деплой весит 700 МБ.

Нужно:
1. Оценить схему: R2-бакет с публичным доступом против прокси через Pages Functions. Выбрать и обосновать.
2. Изменить tools/build_manifest.py: база медиа берётся из переменной (например MEDIA_BASE_URL),
   чтобы приложение получало абсолютные ссылки. Предусмотреть локальную разработку без R2.
3. Проверить, что приложение не завязано на относительные пути.
4. Написать инструкцию для пользователя: как создать бакет, включить публичный доступ, загрузить файлы.

Код не писать до согласования схемы — сначала короткий план.
```

### O2. Ревью перед показом

```
Задача: аудит кода перед публичным показом.

Проверить и отчитаться:
1. Утечки: подписки на audio и mediaSession, таймеры, RAF — всё снимается при размонтировании.
2. Состояния: что будет при ошибке сети, при битом LRC, при пустом каталоге.
3. Media Session: все ли обработчики корректны, нет ли двойной регистрации после навигации.
4. Фан-слой: не растёт ли localStorage бесконечно, не ломается ли при битом JSON.
5. Доступность: тач-таргеты, контраст текста в обеих полярностях.

Формат: список находок с приоритетом, без правок кода.
```

## Что всегда

- Одна задача — одна сессия. После задачи: тесты, сборка, коммит, `/clear`.
- Не вставлять документы в чат: `CLAUDE.md` и `docs/` читаются с диска.
- Деплой запускает человек: `npm run build && npx wrangler pages deploy dist --project-name kishlak-tg`.
