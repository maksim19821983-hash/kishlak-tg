# Передача: где остановились

Файл для новой сессии Claude. Короткий контекст вместо пересказа всей истории: читай это, потом спеки, потом продолжай.

---

## Состояние продукта

Работающий MVP: Telegram Mini App, плеер под артиста Кишлака.

- Открывается **плеером** (кассета), внизу три таба: `ПЛЕЕР`, `КАТАЛОГ`, `ПРОФИЛЬ`.
- Под кассетой — плоский список всех треков (116 из 31 релиза), тап играет.
- Каталог — сетка релизов с кнопкой ▶ у каждого.
- Кадр релиза (тап по обложке) → «СЛУШАТЬ».
- Текст: LRC у 2 треков, остальные без (парсер и вкладыш готовы).
- Аудио: фон и локскрин работают, проверено на iPhone в Телеграме.

Деплой: Cloudflare Pages, `https://kishlak-tg.pages.dev`. Аудио там же (Range не поддерживается — перемотка медленная, планируется R2).

## Что незакоммичено прямо сейчас

Работа оборвалась на середине задачи «шесть правок по фидбеку». В рабочем дереве:

Вероятно, часть пунктов уже сделана (иконки, шапка «сейчас играет»), часть нет. Сначала посмотри диф и оцени, что готово.

## Шесть правок, которые надо довести

1. **Иконки транспорта** — сейчас рисуются эмодзи (⏮ ▶ ⏭), выглядят как синие квадратики и плохо ловят нажатия. Нужны SVG 24×24, stroke 1.5; проверить, что prev/next реально переключают трек.
2. **Убрать кнопку «ПЕРЕВЕРНУТЬ»** — в плоском списке сторона A/B не имеет смысла.
3. **Подписи на кассете**: лейбл — название трека («КИШЛАК — РОСТОВ»), под названием — «КИШЛАК · 02.06.2022 · 2025».
4. **Вернуть «сейчас играет» в шапку каталога и профиля**: `● трек · 0:42` + пауза, тап переключает на плеер.
5. **Кассета визуально**: окно катушек 92 px (сейчас занимает полкорпуса), катушки ближе к центру, видимая лента, ступицы с тремя спицами, hairline по корпусу, лёгкая текстура, винты приглушить.
6. **tools/ingest.py**: пропускать файлы нулевого размера с предупреждением (один трек уже потерялся из-за 0-байтного файла) и принимать `.acc` как алиас `.aac`.

## После правок

```bash
npx vitest run
npx tsc --noEmit
git add -A && git commit -m "fix: иконки, подписи кассеты, шапка «сейчас играет»"
npm run build
npx wrangler pages deploy dist --project-name kishlak-tg
```

Деплой запускает пользователь — wrangler требует его аккаунт.
