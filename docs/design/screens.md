# Экраны

Каждый экран — композиция из `system.md`. Пропорции для 390×844, на других экранах тянется по вертикали.
Живые макеты: `design/sheet-flow.html`, `design/sheet-mini.html`, `design/sheet-fan.html`, `design/sheet-v2.html`, `design/sheet-v3.html`.

Схема: **Каталог → тап по обложке → Кадр релиза → «Слушать» → Кассета → Вкладыш**.
Профиль — отдельно, из шапки каталога. Лента мини-плеера — на всех экранах, кроме главной и кадра.

---

## 0. Запуск

```
┌──────────────────────────────┐
│                              │
│           К                  │  ← монограмма, акцент
│                              │
│        КИШЛАК                │  ← Unbounded 800, 20
│      МИНИ-ПРИЛОЖЕНИЕ         │  ← mono-label
│  ▓▓▓▓▓░░░░░░░░░░░░░░░░░░░░   │
└──────────────────────────────┘
```

Максимум 900 мс, дольше — прогресс вместо логотипа. Нет сети за 6 с — уходим на каталог со скелетонами.

## 1. Каталог (главная)

```
┌──────────────────────────────┐
│ КИШЛАК          12 / 28  (Р) │  ← шапка; если играет — режим C:
├──────────────────────────────┤     «● ВДПС · 0:42        ⏸  (Р)»
│ КАТАЛОГ                      │  ← h1
│ ПРОЯВЛЯЕТСЯ ПО МЕРЕ …        │  ← mono-label
│                              │
│ ┌────────┐ ┌────────┐        │
│ │  ВДПС  │ │ СХИК2  │        │  ← сетка 2×N, зазор 16/14
│ │  01    │ │ 6/11   │        │     штамп = собран
│ └────────┘ └────────┘        │
│ ВДПС        СХИК2            │
│ 2026 · 11/11 2023 · 6/11     │
│                              │
│ ┌────────┐ ┌────────┐        │
│ │Болею…  │ │ Апноэ  │        │
│ └────────┘ └────────┘        │
└──────────────────────────────┘
```

Поведение:
- Тап по обложке → кадр релиза (вариант 1). Долгий тап → «Слушать всё» (опционально).
- Обложка проявляется: серое → цветная копия снизу вверх по доле прослушанных треков, сатурация растёт вместе с прогрессом. 100% — штамп.
- Если играет трек — шапка переключается в режим C: `● название · 0:42`, пауза, кнопка профиля. Тап по шапке открывает кассету.
- Счётчик `12 / 28` — собранные релизы.
- Поиск — иконка в шапке (появляется при скролле вниз).

Состояния: скелетоны (серые блоки 161×161), пусто («каталог ещё собирается»), ошибка (кнопка «Повторить»), офлайн (баннер 40 px над сеткой).

## 2. Кадр релиза

```
┌──────────────────────────────┐
│ 16:34                        │
│                              │
│        ОБЛОЖКА НА ВЕСЬ       │  ← object-fit: cover, без рамок
│             ЭКРАН            │
│                              │
│   ( скрим снизу )            │
│ РЕЛИЗ · 2026                 │  ← mono-label
│ ВДПС                         │  ← display-frame, 52
│ 11 ТРЕКОВ · 4 ПРОСЛУШАНО     │  ← mono-num
│ ▬▬▬▬▬▬░░░░░░░░░░░░░░░░       │  ← ProgressRule
│ (        СЛУШАТЬ        )    │  ← белая пилюля 54
└──────────────────────────────┘
```

- Вход: тап по обложке в каталоге (shared transition на обложке, 300 мс).
- Выход: свайп вниз или кнопка «назад» Телеграма.
- Скрим обязателен: `linear-gradient(to bottom, rgba(0,0,0,.5), transparent 22%, rgba(0,0,0,.4) 55%, rgba(0,0,0,.94) 90%)`. Без него на светлых обложках текст не читается.
- «СЛУШАТЬ» — запускает релиз с первого непрослушанного трека и открывает кассету.
- Свайп влево — следующий релиз каталога (позже, v0.2).

## 3. Кассета (плеер)

```
┌──────────────────────────────┐
│ 01 / 12              КИШЛАК  │
│ ┌──────────────────────────┐ │
│ │ КИШЛАК — ВДПС      №0341 │ │
│ │ ( ● ) ~~~~~~~~ ( ○ )     │ │  ← катушки + лента
│ │ СТОРОНА A     C-60 · 2026│ │
│ └──────────────────────────┘ │
│ ВДПС                         │  ← display-l
│ КИШЛАК · 2026 · СИНГЛ        │
│                              │
│ я вырос там, где свет…       │  ← 3 строки текста, lyric
│ болею тобой                  │  ← lyric-active, акцент
│ и мне не холодно             │
│                              │
│ ДАЛЬШЕ НА КАССЕТЕ            │
│ 02  Ночная смена      3:03   │
│ 03  Двинулся на тебе  2:56   │
│                              │
│ ▬▬▬▬░░░░░░░░░░░░░░░░░░░░     │  ← прогресс
│ 0:42                  −1:38  │
│  ⏮   ( ⏸ )   ⏭   ПЕРЕВЕРНУТЬ│
└──────────────────────────────┘
```

Микровзаимодействия:
1. Катушки крутятся со скоростью воспроизведения; на паузе замирают.
2. Лента перетекает: левая катушка полнеет, правая пустеет — по прогрессу.
3. Тап по корпусу — пауза, haptic `medium`.
4. «Перевернуть» — 3D-флип, сторона B, очередь перестраивается.
5. Тап по строке текста — перемотка (haptic `light`).
6. Конец стороны — кассета «щёлкает», лента стоп, подсказка «перевернуть».

Состояния: загрузка (катушки стоят, окно приглушено), буферизация (точка на ленте), ошибка (корпус приглушён, «трек недоступен»), конец стороны.

│ ВКЛАДЫШ            A · 1/6   │
│ ТЕКСТ ПЕСНИ                  │  ← h2
│ ─────────────────────────    │
│ я вырос там, где свет не …   │
│ где каждый шаг — как …       │
│ болею тобой                  │  ← активная
│ ─────────────────────────    │
│ 01 Болею тобой         2:24  │  ← трек-лист стороны A
│ 02 Ночная смена        3:03  │
│ ─────────────────────────    │

Открывается из кассеты (свайп вверх или тап по превью текста). Закрывается «СЛОЖИТЬ» или свайпом вниз, с анимацией складывания листа.

## 6. Лента мини-плеера

```
├──────────────────────────────┤
│ ▣  ВДПС                     ⏸│  ← 46 px
│    КИШЛАК · 0:42 / 2:12      │
├──────────────────────────────┤
│ ▬▬▬▬▬▬░░░░░░░░░░░░░░░░░░░░    │  ← линия прогресса, 2 px
```

- Видна на всех экранах, кроме главной (там играющее в шапке) и кадра релиза.
- Фон = фон экрана, сверху hairline. Не панель.
- Тап — открыть кассету. Кнопка справа — пауза/плей.

## 7. Поиск и любимые

Поиск — шит из шапки: поле 48 px, фильтры `ВСЁ / ТРЕКИ / РЕЛИЗЫ`, результаты с обложками 44 px, дебаунс 150 мс.
Любимые — секция «ПОЛКА» внизу каталога: лайкнутые треки и плейлисты. Отдельный экран открывается из неё.

> Решение по навигации (нет таб-бара) — на подтверждение: каталог как единственный корень, поиск и профиль в шапке, любимые — из секции. Если нужны табы — вернём три, но тогда шапка упрощается.

## 8. Сквозные правила

1. Один экран — одна мысль, один главный CTA.
2. Полярность следует за обложкой на всех экранах, без исключений.
3. Любое действие — haptic: `light` выбор, `medium` play/pause, `success` лайк, `warning` край очереди.
4. Пустые состояния — голосом продукта, без «упс» и смайликов.
5. BackButton Телеграма закрывает вложенные экраны; на главной его нет.
