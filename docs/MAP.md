# Карта проекта

Одна страница, чтобы не теряться: что решено, что идея, что лежит в папках и что дальше.

---

## Где мы сейчас

Дизайн ещё обсуждается, кода нет. Утверждено: **каталог-печать** + **кадр релиза на весь экран** + **плеер-кассета** + **фан-слой** (проявление обложек, статистика, титул, профиль). Всё остальное — варианты и идеи, которые ждут решения.

Статус документации: `system.md` и `screens.md` переписаны под новую основу. Промты в `docs/prompts/` тоже переписаны — восемь задач по новой схеме (каркас → аудио → полярность → каталог → кассета → вкладыш → фан-слой → Телеграм).

## Что открыто

1. **Навигация без табов** — каталог единственный корень, поиск и профиль в шапке, любимые секцией. Подтвердить или вернуть табы.
2. **Промты надо переписать** под новую схему — иначе Claude соберёт старый вариант.
3. **Аудио-спайк** — фон и локскрин в Телеграме, Media Session. Единственный технический риск.
4. **Контент** — нужны 3–4 трека с обложками и 1–2 `.lrc`, чтобы Claude верстал не на заглушках.

## Папки

```
START-HERE.md              ← с чего начать сборку: шаги и первое сообщение для Claude
CLAUDE.md                  ← главный файл для Claude: правила, стек, границы, дорожная карта
docs/
  design/
    system.md              ← дизайн-система: полярность, токены, типографика, кассета, компоненты
    screens.md             ← все экраны и связки между ними
    variants.md            ← журнал вариантов и идей + схема финальной связки
    backlog.md             ← что добавлять, по версиям; скины; чего не делаем
  spec/
    fan-layer.md           ← ТЗ: проявление, статистика, титул, профиль, данные, приёмка
    content.md             ← права, форматы файлов, структура папок, шаблон письма артисту
    pipeline.md            ← как из папки с треками собрать релиз (автоматизация)
    telegram-setup.md      ← бот, HTTPS-туннель и тест в Телеграме
    artist-letter.md       ← как написать артисту: тексты и порядок действий
  strategy/
    platform.md            ← как переносить в натив и как расти до стриминга
  prompts/
    README.md              ← порядок промтов и как их формулировать
    01…08-*.md             ← задачи для Claude по новой схеме
tools/
  ingest.py                ← сборка релиза: теги, обложка, палитра, LRC, release.json
  build_manifest.py        ← content/ → public/content/manifest.json для приложения
  .venv/                   ← локальное окружение для инструментов (в git не идёт)
design/
  sheet-*.html             ← живые макеты: открыть в браузере
  card.html                ← карточка шаринга
  preview/*.png            ← скриншоты макетов
  assets/                   ← шрифты, обложки (реальные из скриншотов + сгенерированные)
  _build/*.py              ← скрипты сборки макетов (не трогать без нужды)
  archive/                 ← первая итерация дизайна, отклонена
```
