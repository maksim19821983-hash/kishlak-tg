# ТЗ: контент — музыка, обложки, тексты

Самый скучный и самый блокирующий раздел. Без файлов Claude верстает на заглушках, а продукт нельзя показать.

---

## 1. Права: с чего начать

**Правило:** мы не раздаём музыку, на которую у нас нет разрешения. Для Кишлака это значит — **прямой разговор с артистом**.

Почему артисту это выгодно (аргументы для письма):
- приложение-кассета — это про него, а не про «ещё один стриминг»;
- фанаты слушают его каталог без рекламы и без подписок;
- он получает статистику и канал в Телеграме, куда можно анонсировать релизы;
- донаты через Stars идут **ему**, а не «проекту».

Что нужно получить письменно (даже в переписке):
1. разрешение на использование фонограмм в приложении;
2. разрешение на обложки и фото;
3. тексты песен (если есть) — и разрешение их показывать;
4. право на промо-упоминание («официальное приложение артиста» — или «фанатское», если официального статуса нет).

Если артист недоступен: начинать с 1–2 треков, на которые есть разрешение, и не масштабировать каталог до договорённости.

## 2. Форматы файлов

| Что | Формат | Параметры | Размер на трек |
|---|---|---|---|
| Аудио | MP3 320 kbps CBR или AAC 256 | 44.1 kHz, стерео, без обрезки тишины в начале | 7–10 МБ |
| Аудио (премиум) | AAC 256 | тот же мастер | 6–8 МБ |
| Обложка | JPG | 1400×1400, sRGB, качество 90 | 150–300 КБ |
| Обложка превью | JPG/WebP | 400×400 | 30–50 КБ |
| Текст | `.lrc` UTF-8 | таймкоды `[mm:ss.xx]` | 2–6 КБ |
| Фото артиста | JPG | 1600 по короткой стороне | 300 КБ |

Правила:
- Мастер не перекодируем дважды: из WAV/FLAC сразу в финальный MP3 320.
- Нормализация громкости — по желанию артиста, но **одинаково** для всего каталога (LUFS −14, если делаем).
- Обложки — только квадрат, без полей и рамок; если исходник не квадрат, обрезаем по центру.

## 3. Где брать

**Идеально:** артист присылает папку с релизами — мастера, обложки, тексты. Тогда всё честно и в максимальном качестве.

**Если артиста нет под рукой:**
- обложки — с официальных страниц релиза (Bandcamp, Apple Music, VK) в максимальном доступном размере, но **не** скриншотом с телефона;
- тексты — только те, что артист публиковал сам; иначе генерируем LRC по аудио (Whisper + ручная правка).

**Чего не делаем:** не тянем аудио из стриминговых сервисов, не снимаем с YouTube, не берём «deemix»-рипы. Это и есть та причина, по которой чужие боты живут до первого бана.

## 4. Структура папок

```
content/
  artist.json                 # имя, алиасы, био, счётчики, фото
  releases/
    vdps-2026/
      release.json
      cover.jpg               # 1400×1400
      cover-400.jpg
      tracks/
        01-boleyu-toboy.mp3
        01-boleyu-toboy.lrc
        02-nochnaya-smena.mp3
        02-nochnaya-smena.lrc
```

`release.json`:

```json
{
  "id": "vdps-2026",
  "title": "ВДПС",
  "artistId": "kishlak",
  "year": 2026,
  "type": "single",
  "cover": "cover.jpg",
  "coverSmall": "cover-400.jpg",
  "palette": { "mode": "paper", "accent": "#64A4B4" },
  "tracks": [
    {
      "id": "vdps-2026-01",
      "title": "Болею тобой",
      "duration": 144,
      "audio": "tracks/01-boleyu-toboy.mp3",
      "lrc": "tracks/01-boleyu-toboy.lrc"
    }
  ]
}
```

`palette` — на уровне релиза, потому что обложка одна. Считается заранее скриптом (16×16 downsample, средняя яркость + зажатый акцент) и кладётся в JSON — в рантайме ничего не считаем, нет мигания и работает оффлайн.

Файлы генерируются автоматически: `tools/ingest.py`, инструкция — `docs/spec/pipeline.md`.

## 5. Где хранить

| Этап | Где | Почему |
|---|---|---|
| Разработка | `public/audio/` локально, в `.gitignore` | в git не кладём десятки мегабайт |
| Первый запуск | Cloudflare R2 или S3 + CDN | дешево, поддерживает `Range` и CORS |
| Потом | то же + подписанные ссылки | закрываем от прямого скачивания |

Требования к хостингу аудио (иначе плеер поедет):
- поддержка HTTP `Range` (иначе перемотка ломается);
- `Access-Control-Allow-Origin` для домена приложения;
- `Cache-Control: public, max-age=31536000, immutable` для треков и обложек.

## 6. Объёмы

Каталог Кишлака: ~30 треков × 9 МБ ≈ **270 МБ** аудио + ~10 МБ обложек.
Это спокойно живёт на R2 за копейки, но **не** в git.

## 7. Чеклист на каждый релиз

- [ ] разрешение на фонограммы и обложку (переписка сохранена)
- [ ] MP3 320, без клиппинга, длительность совпадает с метаданными
- [ ] обложка 1400×1400 и 400×400
- [ ] `.lrc` с таймкодами, первая строка попадает в вокал ±0.2 с
- [ ] `release.json` заполнен, `id` не меняется после публикации
- [ ] палитра посчитана и записана
- [ ] трек проверен в приложении на iPhone и Android: играет, перематывается, фон не рвётся

## 8. Что делать прямо сейчас

1. Написать Кишлаку (или его менеджменту) — текст письма ниже.
2. Собрать 3–4 трека, на которые разрешение уже есть.
3. Положить их в `content/` по структуре выше и прислать мне — я проверю палитры, LRC и соберу манифест.

### Шаблон письма

> Хотим спросить разрешение использовать фонограммы и обложки, и по возможности получить исходники (или хотя бы MP3 320) и тексты. Донаты через Telegram Stars пойдут тебе, никакой подписки и рекламы не планируем. Показывать можем как «официальное приложение» или как фанатское — как скажешь.
