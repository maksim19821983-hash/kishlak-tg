# Чеклист перед показом людям

Восемь задач реализованы. Дальше — не код, а три вещи: контент, деплой, проверка на телефоне.

---

## 1. Контент

Сейчас: 8 релизов, 74 трека, **LRC только у 2 треков** (Интро и Гордыня из «ВДПС»).

| Что | Сколько | Кто |
|---|---|---|
| Тексты с таймкодами | минимум весь «ВДПС» (9 треков), лучше 20 | ручная разметка ~20 мин на трек |
| Обложки | есть у всех релизов | — |
| Проверка палитр | 8 релизов: 2 бумажных, 6 тёмных | глазами на `/polarity` |

Пока текст есть у двух песен, главная фича продукта видна на двух песнях. Это единственная вещь, которая реально тормозит показ.

## 2. Деплой

Сейчас приложение живёт на туннеле: ссылка меняется, ноутбук должен быть включён. Для показа нужен постоянный адрес.

**Рекомендация:** Cloudflare Pages.

1. Аккаунт Cloudflare → Pages → Create project → Direct Upload (проще всего, без привязки репозитория).
2. Локально: `npm run build`, затем `npx wrangler pages deploy dist --project-name kishlak`.
3. В `dist` обязательно должны попасть `public/content` — иначе каталог будет пустым. Проверить: после сборки в `dist/content/manifest.json` есть файл.
4. Полученный `https://kishlak.pages.dev` вставить в меню-кнопку бота.

Когда появится домен — привязать к проекту, обновить ссылку в BotFather.

Пройти по списку на iPhone, потом на Android, если есть:

- [ ] Каталог открывается, 8 обложек, счётчик релизов
- [ ] Тап по обложке — кадр релиза, свайп вниз — назад
- [ ] «СЛУШАТЬ» — открывается кассета, играет
- [ ] Свернул Телеграм — играет
- [ ] Локскрин — обложка, название, ⏮⏸⏭
- [ ] Перемотка ползунком на локскрине
- [ ] Перемотка линией в кассете: тап и перетаскивание
- [ ] Текст: активная строка совпадает со звуком, тап по строке — перемотка
- [ ] Профиль: пустой при нуле, цифры появляются после прослушивания
- [ ] Прогресс релиза растёт после дослушивания трека
