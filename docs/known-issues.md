# Известные проблемы

Записано по фидбеку с телефона. Чинить по порядку приоритета.

## 1. Переключение треков останавливается после первого нажатия — ВЫСОКИЙ

**Симптом.** Нажал next — переключилось; второе и последующие не срабатывают. На старте: «Ростов» → next → «На двоих» → next → по-прежнему «На двоих».

**Причина найдена.** `PlayerTab` грузит в движок только треки первого релиза: `engine.load(firstRelease.tracks, startIdx)` — в очереди оказывается 2 трека, а не 116. `nextIndex` на последнем треке при `repeat: off` возвращает `null`, движок ставит паузу и остаётся на месте. Счётчик в шапке при этом показывает `01 / 116`, потому что считает по каталогу.

**Чинить так.** Очередь всегда — плоский список всех треков каталога. Стартовая позиция — индекс выбранного трека в этом списке. Кнопка ▶ на релизе стартует с первого трека релиза, но очередь остаётся общей. То же для deep link.

## 2. Не переключается после конца альбома из одного трека — ВЫСОКИЙ

Тот же корень: очередь = релиз, на последнем треке она кончается.

## 3. Прогресс прослушивания пропадает после обновления страницы — ВЫСОКИЙ

Послушал альбом → обложки стали цветными → обновил → снова серые. Значит `FanState` не сохраняется или не читается при старте. Проверить: запись в localStorage по `kishlak:fan:v1`, момент flush (throttle 10 с, force на pause/visibilitychange), чтение при инициализации стора.

## 4. Полярность меняется сама при переключении трека — ОТКЛОЖЕНО

Тема перекрашивается под обложку. Решено: пока отключить автоматику, добавить ручной переключатель темы. Автоматику доводить после запуска.

## 5. Лента «сейчас играет» приклеена к верху — НИЗКИЙ

Должна скроллиться с контентом. В неё же добавить prev / play-pause / next.
